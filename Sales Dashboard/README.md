# 📊 Sales Dashboard – Customer Shopping Analysis

## Project Overview

The **Sales Dashboard** is an interactive data analysis project developed using Microsoft Excel. It focuses on analyzing customer shopping behavior, purchase patterns, and sales-related information to identify meaningful trends and insights.

The project uses a customer shopping behavior dataset containing **14,332 customer records**. It helps explore purchasing habits across different product categories, customer demographics, locations, seasons, and payment methods.

##  Project Objectives

- Analyze customer purchasing behavior and spending patterns.
- Understand sales distribution across product categories.
- Explore customer demographics, including age and gender.
- Compare purchasing trends across different locations and seasons.
- Present data through dashboards and visualizations.
- Support better business decisions using data-driven insights.

##  Tools and Technologies

- **Microsoft Excel** – Data analysis and dashboard development.
- **Pivot Tables** – Summarizing and analyzing customer data.
- **Charts and Visualizations** – Presenting trends and comparisons.
- **Data Cleaning** – Preparing data for analysis.
- **Excel Dashboard** – Displaying important information in a structured format.

##  Dataset Description

The dataset contains customer shopping information with fields such as:

- Customer ID
- Age and Gender
- Item Purchased
- Product Category
- Purchase Amount (USD)
- City
- Size and Color
- Season
- Review Rating
- Order Status
- Shipping Type
- Discount Applied
- Promo Code Used
- Payment Method
- Frequency of Purchases
- Age Group
- Previous Purchases

##  Key Areas of Analysis

- **Customer Analysis:** Understand customer demographics and shopping habits.
- **Product Analysis:** Explore product categories and frequently purchased items.
- **Purchase Analysis:** Examine purchase amounts and spending patterns.
- **Geographical Analysis:** Compare customer activity across locations.
- **Seasonal Analysis:** Study purchasing patterns across different seasons.
- **Payment Analysis:** Explore the use of different payment methods.
- **Customer Behavior:** Analyze purchase frequency, discounts, and promotional offers.

##  How to Use

1. Download the Excel file from this repository.
2. Open `Sales Dashboard.xlsx` in Microsoft Excel.
3. Navigate to the **DASHBOARD** worksheet.
4. Explore the available dashboard visualizations and summaries.
5. Use the underlying dataset and pivot tables to examine customer shopping patterns.
