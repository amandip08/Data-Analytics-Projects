# IPL Auction Dashboard

## Project Overview

The IPL Auction Dashboard is an interactive Power BI project that analyzes IPL Auction 2023 data. The dashboard provides insights into player prices, team expenditures, and player nationality distribution through visual analytics.

## Features

* Player Price Analysis
* Team-wise Total Expenditure
* Nationality Distribution of Players
* Interactive Filters and Slicers
* Dynamic Data Visualization
* User-Friendly Dashboard Design

## Dashboard Visualizations

### 1. Price of Players

Displays the auction prices of players and helps identify high-value purchases.

### 2. Team's Total Expense

Shows the total amount spent by each IPL franchise during the auction.

### 3. Players by Nationality

Visualizes the distribution of players from different countries using a donut chart.

### 4. Player Style Filter

Allows users to filter dashboard insights based on player categories.
