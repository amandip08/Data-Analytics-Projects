## Customer Behavior Analytics Project
An end-to-end data analytics project analyzing customer shopping behavior using SQL, Python, and Power BI. 
This project demonstrates the complete data pipeline — from raw data extraction and transformation to interactive dashboard visualization.

## Tools & Technologies
SQL – Data extraction, querying, and database management
Python (Pandas) – Data cleaning, transformation, and preprocessing
Power BI – Interactive dashboards, DAX, and data visualization

## End-to-End Pipeline Workflow
This project follows a structured approach for each analysis:

1️⃣ Data Transformation (Python / Pandas)
Loading raw data into Pandas DataFrames
Handling missing values, duplicates, and outliers
Feature engineering and creating calculated columns
Data type conversions and standardization
Exporting cleaned data for Power BI consumption

2️⃣ Data Extraction (SQL)
Writing complex SQL queries to extract raw data from relational databases
Joining multiple tables, filtering, aggregating, and creating views
Exporting query results as CSV files for further processing

3️⃣ Data Visualization & Reporting (Power BI)
Loading cleaned data into Power BI
Building data models and relationships
Creating calculated columns and measures using DAX
Designing interactive dashboards with slicers, filters, and drill-throughs

## Project Highlights
Data Pipeline
The project processes a comprehensive customer shopping dataset containing demographic information, purchase history, product preferences, and engagement metrics. 
The data flows through a structured pipeline where raw CSV data is first cleaned and transformed using Python's Pandas library, then analyzed using SQL for specific business questions, and finally visualized through an interactive Power BI dashboard.

## Dashboard Features
The Power BI dashboard provides real-time insights into customer behavior with:
KPI Cards displaying key metrics like total customers, average purchase amount, and average review ratings
Interactive Filters allowing users to segment by gender, subscription status, and payment methods
Revenue Analysis broken down by product categories and customer age groups
Subscription Analytics showing distribution of subscribed vs. non-subscribed customers
Sales Distribution across different product categories and shipping methods

## Business Impact
This end-to-end solution enables stakeholders to:
Make data-driven decisions about product inventory and marketing strategies
Understand customer segments and their purchasing patterns
Optimize promotional campaigns based on discount usage patterns
Improve customer engagement through subscription program insights
Monitor business performance through key metrics
